  • 写出份量，如「米饭 150g」而不是「一些米饭」

ABOUT

作品说明

「食安智荐」是《人工智能基础与应用》课程的实践作品。它把图像/文本输入、营养结构化和食谱推荐串成一条短路径：AI 负责生成与归纳，人负责确认与取舍。

当前版本为离线演示版：识别候选与营养计算基于内置的食物成分表和规则库，不需要 API 密钥即可运行，适合课堂演示与源码检查。若要接入真实多模态大模型，可按源码中 README.md 的说明替换 recognizeDish() 与 buildMealPlan() 两个函数。
